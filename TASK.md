# Milestone 1 — Basic Username/Password Auth

## Цель

Добавь аутентификацию. Сейчас каждый эндпоинт открыт, а на фронте есть дропдаун для переключения
между пользователями. Это нужно заменить полноценным входом.

## Требования

1. Добавь аутентификацию по логину-паролю.
2. Эти эндпоинты оставь открытыми: 
  - `/api/init-db`
  - `/actuator/health`
  - `/actuator/info`
  - `/swagger-ui.html`
3. Пароли можешь пока сохранить плейн-текстом. Там позже будет сайд-квест на то, чтобы настроить
   хеширование и солт, но если знакома с этими концептами, можешь сразу реализовать условный
   BCrypt. Только пароли запиши куда-нибудь. :]
4. На фронте (можно нейронкой):
  - На главной и на экране проекта сверху справа есть менюшка для переключения пользователей. Ее
    нужно удалить.
  - Там же, сразу, удалить `localStorage.currentUserId` и всю логику, которая на это завязана.
  - Замени эту меню на небольшой блок, показывающий текущего пользователя, плюс
    **кнопка для лог аута**. Этот блок дб на главной, на странице проекта и на админке.
  - Можно оставить дефолтный логин экран, можно попросить нейронку сгенерить что-то.

## Здесь не нужны

- Роли/полномочия — это в следующем майлстоуне (`02-rbac`).
- Сессии, токены, OAuth2/OIDC — все тоже будут позже.

## Проверки

Прямо по пунктам из требований
